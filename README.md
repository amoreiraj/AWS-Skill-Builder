# AWS Skill Builder

This repository documents my learning journey through the AWS Cloud Practitioner Essentials course, taken via AWS Skill Builder.
The goal of this project is to consolidate foundational AWS knowledge, track progress module by module, and build a structured reference that can be revisited and expanded as I move into more specialized cloud and data engineering topics.

This is a learning and documentation repository, not a production project.

---

## Course Overview

- Course: AWS Cloud Practitioner Essentials

- Platform: AWS Skill Builder

- Format: Digital course

- Duration: ~12h 45m

- Language: English

- Level: Foundational / Beginner

---
## Focus: Core AWS concepts, services, pricing, security, and architecture principles

The course provides a broad understanding of AWS services and cloud concepts, aligned with the AWS Certified Cloud Practitioner exam objectives.

--- 
## Learning Objectives

- Understand what cloud computing is and how AWS operates at a global scale

- Learn core AWS services across compute, storage, networking, databases, and security

- Understand AWS pricing models, billing, and support plans

- Gain awareness of AWS best practices, including the Well-Architected Framework

- Build a solid foundation for future specialization (Data Engineering, Cloud Engineering, DevOps)

---
## Repository Structure

Each module will have its own folder containing notes, summaries, and (when applicable) diagrams or examples.
